CallGrader

Grades a voice agent's phone call the way a QA reviewer would: did it pass, did it make something up, did it miss a handoff to a person, did it resist a prompt injection. Every verdict points at the lines that caused it.

Verdict

Pick a test call or paste one, then grade it.

ModernBERT fine-tuned in PyTorch on 1,260 voice-agent calls. Scores are probabilities; the cut-off for each label was tuned on validation calls.
